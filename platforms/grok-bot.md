# Grok Bot

The original Agentic Butler still lives as a Grok Bot template:

https://x.ai/bot/gnwO_M9gMWTJ8xhUzjFi4

Install that if you want the version this pack was ported from. It has its own computer and browser, connectors, a vault, routines on a clock, and full-screen nudges on a registered Mac. Those are the pieces this pack does not pretend to have.

This repository is the same butler for Claude and ChatGPT: the 16 skills, the four rituals, and the 7-day setup, as documents and phrases. You do not need the template and this pack both running unless you want two butlers.

The challenge still finishes inside your own assistant. You do not need to message anyone to move from one day to the next.
