# Onboarding

The assistant runs these files. The owner can read `lessons/` for the same week in the course's voice.

| File | Who it is for |
| --- | --- |
| `guided-setup.md` | Nine steps, if they are not doing the challenge |
| `challenge.md` | Rules, the morning kickoff, the day map |
| `day-1.md` … `day-7.md` | The script for that day. Read it before asking |
| `lessons/` | The course pages, including what to post if they are in the community |
| `images/` | The Day 4 menu and the Day 7 picture of how it fits together |

Say "I'm doing the 7-day challenge" to start. "pause" and "resume" work. Nothing waits on a message to another person.
