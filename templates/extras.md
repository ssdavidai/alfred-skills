# Extras

Day 4. One block per extra they set up.

```
## [name]
Set up: [what was actually done]
Test: [passed / failed: why]
Rule: [the rule they wrote, or —]
```

About five. At least one rule in their own words, and at least one event-style ritual if the product can do it or they accepted a paste-instead phrase. Nothing is sent, posted or shared while these are set up.
